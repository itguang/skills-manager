# 技能包文件查看与编辑能力（uTools 子页面）

## 1. 背景

当前 skill 列表仅支持展示 skill 的基础信息，无法查看技能包内部文件结构，也无法对技能包文件进行编辑（如 `SKILL.md`、脚本文件等）。

这导致：

* Skill 调试效率低
* 配置修改不便
* 技能包管理能力不足

因此需要提供技能包文件的查看与编辑能力。

---

## 2. 目标

在 uTools 插件中提供技能包管理能力，支持：

* 从 skill 列表进入技能包管理页面
* 查看技能包目录结构
* 查看文件内容
* 编辑文本类文件
* 保存修改到本地

---

## 3. 非目标（第一版不做）

* 新建文件
* 删除文件
* 重命名文件
* 多标签页
* 文件搜索
* diff 对比
* Git 集成

---

## 4. 用户流程

```text
打开 uTools 插件
  → 进入 Skill 列表页
  → 点击某个 skill name
  → 打开该 skill 的独立子页面
  → 左侧浏览文件树
  → 点击文件
  → 右侧查看 / 编辑内容
  → 点击保存
```

### 9.1 编辑能力

* 切换文件
* 返回上一页

```text

[保存并继续] [放弃修改] [取消]
```

### 核心逻辑

#### 编辑器分发

```ts
function getEditorType(ext: string) {
  if (ext === 'md') return 'markdown'
  if (['js','ts','py','json','yaml','yml','sh','txt'].includes(ext)) return 'code'
  if (['png','jpg','jpeg','gif','webp','svg'].includes(ext)) return 'image'
  return 'unsupported'
}
```
